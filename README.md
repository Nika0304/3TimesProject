# 3Times

Aplicație de realitate augmentată pentru Android care adaugă peste orașul real povestea locurilor.
Totul se controlează din **cursorul timpului**: Trecut (fațade istorice, momentul 1989),
Prezent (urmele lăsate de oameni) și Viitor (capsule ale timpului).
Prima versiune acoperă Piața Victoriei din Timișoara, de la Operă până la Catedrală.


## Structura repo-ului

| Folder      | Ce conține                                                       |
|-------------|------------------------------------------------------------------|
| `unityapp/` | Aplicația mobilă (Unity 6.3 LTS, C#, AR Foundation, ARCore Extensions) |
| `backend/`  | Serverul (Java 17, Spring Boot, PostgreSQL + PostGIS), mai târziu |
| `content/`  | Conținutul istoric: locuri, momente, fotografii (cu sursă și licență) |
| `docs/`     | Documentația și ghidurile de configurare                         |
